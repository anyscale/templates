# Python additions to the base image, for reproducing this template off Anyscale.
#
# On Anyscale you do not need this file: the template's image
# (us-docker.pkg.dev/.../nextflow-genomics-on-ray:2.58.0) already has all of it.
# It is here so the same environment can be rebuilt elsewhere, and so the pins are
# reviewable in the repo rather than only inside a layer.
#
# Base image: anyscale/ray:2.58.0-py312-cu128
#   ray 2.58.0, python 3.12.13, numpy 2.2.6, pandas 2.3.3, pyarrow 23.0.1,
#   matplotlib 3.10.8, ipykernel 7.2.0
#
# Ray is deliberately absent. Installing it here would let pip pull a second Ray
# over the image's own, and a driver and its workers on different Ray versions is
# the one failure `ext.image` cannot survive.
#
# matplotlib is *not* listed for the same reason in reverse: the image ships
# 3.9.4 and the notebook is written against it. Pinning "the newest" here would
# quietly upgrade it on every rebuild.

# --- the GPU annotation leg -------------------------------------------------
# Runs in two places, on purpose: the ANNOTATE_VARIANTS process calls
# bin/score_variants.py through Nextflow, and the notebook's Ray Data step calls
# the same module over the whole callset. One implementation, seen twice.
#
# torch itself is NOT here -- it needs the CUDA-128 wheel index and lives in
# tools/requirements.gpu.txt, which pins it with its own --index-url. Splitting
# it out keeps --extra-index-url off this file, so nothing else can be silently
# resolved from a non-PyPI index.
transformers==5.15.0
huggingface-hub==1.0.5
safetensors==0.7.0
tokenizers==0.23.4

# --- notebook and staging ---------------------------------------------------
# The notebook fetches demo data anonymously; boto3 is in the image but the CLI
# is not, and `aws s3 cp --no-sign-request` is what the README tells you to run.
# (Anonymous, not signed: a signed request is evaluated against the node's role
# and can fail on a public bucket where anonymous succeeds.)
awscli==1.42.30
