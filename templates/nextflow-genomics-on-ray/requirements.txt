# Python additions to the base image, for reproducing this template off Anyscale.
#
# On Anyscale you do not need this file: the template's image
# (us-docker.pkg.dev/.../nextflow-genomics-on-ray:2.58.0) already has all of it.
# It is here so the same environment can be rebuilt elsewhere, and so the pins are
# reviewable in the repo rather than only inside a layer.
#
# Base image: anyscale/ray:2.58.0-py312-cu128
#   ray 2.58.0, python 3.12.13, numpy 2.2.6, pandas 2.3.3, pyarrow 23.0.1,
#   matplotlib 3.10.8, ipykernel 7.2.0
#
# Ray is deliberately absent. Installing it here would let pip pull a second Ray
# over the image's own, and a driver and its workers on different Ray versions is
# the one failure `ext.image` cannot survive.
#
# matplotlib is *not* listed for the same reason in reverse: the image ships
# 3.10.8 and the notebook is written against it. Pinning "the newest" here would
# quietly upgrade it on every rebuild.
#
# Checked against dependencies/images/ray-2.58.0-py312-cu128.freeze.txt with
#   uv pip compile --python-version 3.12 --python-platform x86_64-manylinux_2_28 \
#       -c <freeze> requirements.txt <torch==2.9.1>
# which resolves with every package the image already has left at its image
# version. The additions are torch's own dependencies and the five below.

# --- the CNN arm: GATK's NVScoreVariants ------------------------------------
# NVScoreVariants is a Java front end that runs GATK's Python package,
# `scorevariants`, which imports torch, pytorch_lightning (and the lightning_fabric
# it carries), pysam and Bio. The package itself is installed from the GATK
# source by the Dockerfile; torch lives in tools/requirements.gpu.txt, which pins
# it with its own --index-url, so nothing else here can be resolved from a
# non-PyPI index.
#
# GATK 4.6.2.0's own environment (scripts/gatkcondaenv.yml.template) is Python
# 3.10 with torch 2.1 and pytorch-lightning 2.4.0, pysam 0.22.0 and biopython
# 1.84. This image is Python 3.12 with torch 2.9.1, so:
#
#   pytorch-lightning 2.6, the line Lightning's compatibility matrix tests up to
#   torch 2.10 (2.4 stops at 2.6); lightning-utilities and torchmetrics are its
#   dependencies, at the versions it resolves to;
#
#   pysam 0.22.0 and biopython 1.84, GATK's own pins, which have cp312 wheels.
#
# tools/smoke-nvscorevariants.sh runs NVScoreVariants against exactly these, and
# the image build runs it.
pytorch-lightning==2.6.6
lightning-utilities==0.15.3
torchmetrics==1.9.0
pysam==0.22.0
biopython==1.84
