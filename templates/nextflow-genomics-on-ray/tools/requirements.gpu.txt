# torch, from the CUDA-12.8 wheel index.
#
# Separate from ../requirements.txt because of `--index-url` below. That
# directive replaces the default index for everything installed from this file,
# so it has to be the *only* thing in the file -- put it in the main requirements
# and every package there becomes resolvable from a non-PyPI host.
--index-url https://download.pytorch.org/whl/cu128

# A +cu128 build, to match the base image (anyscale/ray:2.58.0-py312-cu128).
#
# 2.9.1 is the version NVScoreVariants was checked against
# (tools/smoke-nvscorevariants.sh), not a ceiling. The cu128 index also carries
# 2.10.0 and 2.11.0 builds for cp312, and they stay on CUDA 12.8 (2.11.0+cu128
# declares cuda-toolkit==12.8.1 and nvidia-cudnn-cu12), so moving up is a re-test
# of NVScoreVariants and of Lightning's torch range rather than a base-image
# change. Only the default PyPI builds moved to CUDA 13.
#
# Declares no numpy constraint, so the image's numpy 2.2.6 -- which pyarrow and
# Ray Data are built against -- is left alone.
torch==2.9.1+cu128
